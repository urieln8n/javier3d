# Deployment

## Vercel
1. Push repository to GitHub.
2. Import into Vercel.
3. Set environment variables from `.env.example`.
4. Validate preview deployment.
5. Run mobile/desktop browser QA.
6. Only connect the production domain after factual/legal review.

## Domain
Do not purchase or bind a final umbrella domain until naming and brand permissions are confirmed. Hornos JAVA can remain the product brand while a future pizzeria bundle brand can host Hornos JAVA + PedidoAI.
