# Design Direction

## Tone
Premium, warm, Mediterranean, industrial, credible. Avoid generic SaaS neon/glassmorphism.

## Visual system
- Background: near-black warm brown
- Panels: dark espresso / graphite
- Accent: warm brass / ceramic amber
- Typography: editorial serif for large headlines + clean sans for UI
- Photography: warm restaurant context, real product photography prioritized
- 3D: product is hero; environment supports, never competes
